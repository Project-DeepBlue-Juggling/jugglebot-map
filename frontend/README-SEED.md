# frontend/ seed

This directory is seeded from the owner's reference frontend (supplied by the owner from the Windows box; no script here fetches it) in its own commit. That seed commit applies the strip list from decision #31 and nothing else; the two new pages come after it. Checklist for the seed commit: drop Timeline; Team Roles; the Project settings page; My Tasks; BOM, catalogue, stock, builds and units; Brief; Availability; Teams hosting; Entra/MSAL; notifications (bell and stream); comments; the audit-log undo (`UndoListener`, `POST /undo`); multi-user roles and the membership UI; all three auth providers and `SignInPage`; the five stock views (List, Backlog, Board, Canvas, Timeline); the `ui/bugReport*` and `ui/EnvironmentBanner*` files (the only places an upstream name appears; a grep for it is a CI check); the vitest files in stripped directories and the 13 Playwright e2e specs. Add: a ~30-line `StaticAuthClient` returning `GET /users/me` (no `X-Dev-User`, no `?as=`, the production-build `local-dev` guard removed), the `stage` -> `kind` rename, and a ten-line `/events` handler that refetches tasks, dependencies and the project on `invalidate`.
